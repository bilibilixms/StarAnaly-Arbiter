# 第 6 周：前端工作台完整流程

本周在现有 Vue 任务详情页接入第 2～5 周的后端能力。任务列表与创建流程沿用已有页面；进入任务详情后可上传文件、发起异步执行并查看结果。

## 页面行为

- CSV 区域上传 `.csv`，列出文件名、行数、字段和大小，可预览前 20 行。单文件上限 5 MiB。
- 资料区域上传 UTF-8 `.txt`、`.md`、`.markdown`，列出片段数和大小。单文件上限 1 MiB。删除前会确认；删除后原文及结构化引用清空，历史文字回答仍保留。
- 提问使用 `POST /api/tasks/{id}/runs` 异步执行接口。页面每 2 秒刷新执行中任务，展示最近 20 次执行及其步骤、失败原因、CSV 结构化分析结果和资料引用。选择历史执行可查看对应结果。
- 执行失败后可修改问题重新提交；同一页面内提交的问题会回填到输入框。上传失败、加载失败均显示原因和可用的重试入口。
- API 报错优先显示后端 `ProblemDetail.detail`，文件大小在前端先校验，后端仍负责最终校验。

## 测试机浏览器验收

在已配置 MySQL 和 DeepSeek 的机器拉取代码，启动后端，并在 `frontend/` 中执行 `npm install`、`npm run build`、`npm run dev`。浏览器打开 `http://localhost:5173`：

1. 新建任务，上传 `fixtures/monthly-sales.csv`。检查显示 4 行、`date/category/amount` 三列，预览前 4 行。
2. 提问：“请调用 summarize_csv，按 date 月份汇总 amount，给出每月金额与总计。”等待页面自动刷新。检查工具步骤与结构化结果：2026-01 为 300、2026-02 为 200、总计 500。
3. 在另一个任务上传 `fixtures/knowledge-demo.md`，提问：“请先检索资料，再回答普通订单何时可以申请退货，并注明资料名和行号。”检查回答和“资料来源”区域包含第 3 行与 14 天。
4. 删除资料，确认当前执行的结构化引用清空、资料列表为空；历史文字回答仍保留。
5. 可选：断开后端后刷新页面，核对错误提示和重试按钮；恢复后端后重试。执行失败后核对错误原因及重新提交入口。

前端构建和真实浏览器联调需要在测试机完成，结果可追加到 `fox.md`。不要在报告中记录密钥。
